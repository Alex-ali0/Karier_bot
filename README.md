# 🎯 Career Advisor Bot

Телеграм-бот, который помогает подросткам и взрослым найти профессию мечты.

Бот задаёт вопросы о интересах, навыках и предпочтениях, анализирует ответы и рекомендует 3 подходящие профессии. Можно изучать профессии, сохранять избранные и получать подробную информацию.

---

## ✨ Возможности

- 🧠 **Тест на профориентацию** — 15 вопросов с учётом интересов, навыков, склада ума и возраста
- 🎯 **Персональные рекомендации** — 3 профессии на основе ответов
- 🔍 **Поиск профессий** — напиши название, и бот расскажет подробнее
- ⭐ **Избранное** — сохраняй понравившиеся профессии
- 📊 **База из 40+ профессий** — от программиста до фотографа
- 💾 **Сохранение истории** — все тесты и просмотры сохраняются в БД

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/your-username/career-bot.git
cd career-bot
```

### 2. Установи зависимости

```bash
pip install pyTelegramBotAPI
```

### 3. Получи токен бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username
4. Скопируй токен

### 4. Настрой токен

Открой `config.py` и вставь свой токен:

```python
BOT_TOKEN = "ТВОЙ_ТОКЕН_ЗДЕСЬ"
```

### 5. Запусти бота

```bash
python bot.py
```

Готово! Бот запущен и готов к работе 🎉

## 📊 База данных

Бот использует SQLite. Все таблицы создаются автоматически при первом запуске.

### Таблицы

| Таблица | Назначение |
|---------|-----------|
| `users` | Данные пользователей (имя, возраст, дата регистрации) |
| `test_results` | Результаты тестов |
| `professions` | Справочник профессий |
| `favorites` | Избранные профессии пользователей |
| `views_history` | История просмотров профессий |

### Формат профессии

```python
"Программист": {
    "category": "IT",
    "description": "Создает сайты, приложения и программы",
    "salary_min": 80000,
    "salary_max": 300000,
    "education": "Курсы или высшее",
    "skills": ["Python", "Логика", "Алгоритмы"],
    "tags": ["техника", "логика", "умственная", "math", "один"],
    "resources": ["Stepik", "Coursera", "Skillbox"]
}
```

## 🎮 Как пользоваться

### Пройти тест

1. Нажми **🚀 Начать тест**
2. Введи свой возраст (от 10 до 100)
3. Ответь на 15 вопросов
4. Получи 3 рекомендации

### Найти профессию

1. Напиши название профессии (например, `Программист`)
2. Бот покажет описание, зарплату, навыки и ресурсы

### Сохранить в избранное

1. Найди профессию
2. Нажми **⭐ Сохранить**
3. Смотри избранное через **⭐ Избранное**

---

## 🧠 Как работает алгоритм рекомендаций

Бот анализирует ответы по нескольким категориям:

- **Интересы** — что нравится делать
- **Навыки** — что умеешь
- **Стиль работы** — команда или одиночка
- **Склад ума** — математический / гуманитарный / творческий
- **Предпочтения** — стабильность, свобода, бизнес

Каждый ответ добавляет или отнимает баллы у профессий в зависимости от их тегов. В конце выбираются 3 профессии с наибольшим количеством баллов.

## 🔧 Расширение

### Добавить профессию

Открой `professions.py` и добавь новую запись в словарь `PROFESSIONS`:

```python
"Новая профессия": {
    "category": "Категория",
    "description": "Краткое описание",
    "salary_min": 50000,
    "salary_max": 150000,
    "education": "Образование",
    "skills": ["Навык 1", "Навык 2"],
    "tags": ["тег1", "тег2"],
    "resources": ["Ресурс 1", "Ресурс 2"]
}
```

### Добавить вопрос

Открой `test_data.py` и добавь новый вопрос в список `QUESTIONS`:

```python
{
    "id": 16,
    "text": "Твой вопрос?",
    "category": "interests",
    "type": "yesno"  # или "choice"
}
```
